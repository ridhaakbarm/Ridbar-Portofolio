# RidBar Portofolio

Professional portfolio website for manufacturing systems, production monitoring, maintenance workflows, lab dispatch, and internal enterprise applications.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- lucide-react

## Run Locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```
